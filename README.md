# Amita’s Job Search HQ

## Ready now

The included `index.html` is the complete dashboard. It adapts the original Job Search HQ layout for Amita Jethani, using her supplied three-page resume. It is a standalone static page: no build, dependencies, API keys or database are required.

- Five UAE job leads researched on 2 November 2026, with fit explanations and availability caveats.
- UAE selected by default; country filters restricted to the six GCC states.
- Resume-derived profile and skills, application-status tracking, shortlist copying and CSV export.
- Two UAE recruiter website links and a reusable introduction for their forms.
- Browser-local tracking, isolated from Pulkit’s dashboard, plus backup export and restore.
- Mobile and desktop layout checked. Initialization, filters, search, status persistence and shortlist controls tested.

## Publish separately

1. In your GitHub account, create a separate repository, for example `amita-job-hq`. Do not overwrite `job-search-hq`.
2. Extract this ZIP and upload `index.html` to the root of the new repository; commit the upload.
3. In the repository’s Pages settings, configure deployment from the branch containing `index.html`, using its root directory.
4. Once deployment succeeds, open the website address GitHub displays. Use that address on Amita’s mobile.

If using a publicly visible repository or site, anyone with access can see the dashboard’s professional profile and job list. Her phone number, email address, original resume and LinkedIn contact details are deliberately not embedded in the page. Application choices remain in each browser, not in the repository.

## Important limits

This is a research snapshot, not a live jobs feed. Five leads does not mean five confirmed-open vacancies; check the availability notes and original job descriptions. Contract duration and compensation were not assumed. No applications have been sent. No email workflow or automatic refresh is configured. No jobs outside the GCC are included, and no other-GCC vacancies have been seeded yet.

Tracking does not sync across devices. Export a tracking backup before clearing browser storage, changing browsers or moving the site.
